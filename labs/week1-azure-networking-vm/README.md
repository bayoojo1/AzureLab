Week 1 Project: Azure Networking + Virtual Machines
Project Overview

This project demonstrates the deployment of a simple Azure infrastructure environment using PowerShell. It is designed as the first hands-on project in an Azure Cloud Engineer learning roadmap.

By the end of this project, you will have:

A Resource Group
A Virtual Network (VNet)
Two Subnets (web-subnet and app-subnet)
A Network Security Group (NSG)
Two Virtual Machines:
vm-web-01
vm-app-01

All resources are deployed using PowerShell and can be recreated from scratch.
